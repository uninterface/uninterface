# UiCollectionActionVariant

```ts
type UiCollectionActionVariant = 'bordered' | 'soft' | 'text'
```

Import from `@uninterface/uninterface`. The value selects a record-action surface through [uiCollectionActionVariant](../../strategies/uiCollectionActionVariant.md). Bordered preserves ordinary action treatments, including mixed filled and outline buttons; soft requests a subdued tinted surface; text requests no persistent fill/boundary. Omission leaves the backend to choose a default from this vocabulary. None changes action content, semantic color or behavior. Implementations retain native focus and interaction feedback. Verify icon/text modes independently and preserve defaults when the strategy is removed.
