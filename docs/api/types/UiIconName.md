# UiIconName

Import from `@uninterface/uninterface/icons`. The 52 default literal names plus extensible strings. Type acceptance alone does not prove a runtime mapping exists: UiIcon rejects unknown names. Prefer namespaced plugin/domain names such as `billing.invoice`. See [the catalogue](../constants/uiIconNames.md) for default meanings.

Verification: a registered extension renders; an unregistered extension fails visibly.
