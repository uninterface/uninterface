# UiPopoverAlign

Union start | center | end; default start. Requests alignment along the preferred attachment side. Horizontal start/end follow anchor writing direction; along a vertical edge they align top/bottom. Viewport constraints can adjust final geometry. Backend mechanics own positioning; business content stays mounted through repositioning. Verify all alignments, RTL, long content and visual viewport changes.

See [drawers and popovers](../../guides/drawers-and-popovers.md) for composition, ownership and evidence limits.
