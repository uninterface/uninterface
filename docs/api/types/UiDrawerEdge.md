# UiDrawerEdge

Union start | end | top | bottom. Drawer default is end. Start/end follow the rendered writing direction; top/bottom attach to the corresponding viewport or docking-host edge. Core validates vocabulary; the backend supplies themed dimensions, safe-area clearance and scrolling. This does not select docking, displacement, compactness or modality. Verify all edges in LTR/RTL and narrow viewports.

See [drawers and popovers](../../guides/drawers-and-popovers.md) for composition, ownership and evidence limits.
