# collectionSortSelect

Import from `@uninterface/uninterface`. A stable UiCollectionPanelAdaptation<UiCollectionSortPanelContext>, named `sort-select`, for single-sort bindings. It is a backend-independent view object, not a standard UiXxxx component.

Renders a native-backed field selector containing “No sort” and each source-authorized field. Selecting a field applies one rule immediately; the first choice starts ascending, and replacing a field retains the current direction. Selecting No sort requests an empty sort array, restoring source-default ordering. The localized “Sort by” text, selector, direction and removal actions share one horizontal editor row. The selector receives the remaining row width; the label and action buttons retain their content widths. UiField retains the accessible name through a hidden-label strategy; the view supplies the visible inline text, including on backends with floating-label defaults. An adjacent direction icon button appears only when a rule exists and reverses ascending/descending. Accessible labels retain the field/direction meaning. A danger-colored trash action appears with an active rule, clears sorting directly and returns focus to the selector. No sort remains an explicit selector choice and the empty-state display. There are no Add, movement or Apply controls.

Pass it as UiCollectionHeader's sortPanel or invoke view({ binding }). Select it only for binding.mode='single'; it guards incompatible multiple-mode actions rather than truncating a multi-rule query. collectionSortPanel delegates to this presentation automatically for single-mode bindings. Explicit badge selection remains available independently.

The source query owns accepted state. The view's field only bridges UiSelect interaction; external changes update it without a query. Disabled, unsupported and stale selections are guarded, and rejected requests restore source state. Mounting, switching and unmounting do not request data. Entry resources are disposed with the view.

Verify No sort → field → direction → replacement field → trash removal, keyboard focus returning to the selector, No sort selection, one request per change, external synchronization, disabled actions and no reads on remount. Check native pickers, labels, direction-button alignment, narrow wrapping and keyboard use across backends in a browser.
