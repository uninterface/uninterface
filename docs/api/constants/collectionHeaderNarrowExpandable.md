# collectionHeaderNarrowExpandable

Import from `@uninterface/uninterface`. Built-in [UiCollectionHeaderAdaptation](../types/UiCollectionHeaderAdaptation.md), named `narrow-expandable`. A stable, frozen object; no registration is required.

First row: growing search, Filter and Sort icon triggers for their respective supplied slots, then optional Reset. Exactly one query panel can be open; selecting the other trigger switches panels, selecting the open trigger collapses it. The expanded panel follows search and precedes actions. Actions retain their own row (the second row while collapsed); optional info comes last. Missing groups reserve no row. Reset stays available outside both panels and delegates to the supplied ordinary button binding.

Each trigger independently uses its business-supplied active count for native primary/default color and its accessible name/hint. Applied activity survives closing the panel. Expanded state is separately exposed through aria-expanded/controls. Search receives inline header-search usage; the default filter panel supplies filter-form/panel/stacked context. A selected replacement filter collection can supply a different context; sort content uses its own binding.

Use with [uiCollectionHeaderPresentation](../../strategies/uiCollectionHeaderPresentation.md). It is the default for the mobile environment. Its actual Vue render implementation owns the toggles, mutual exclusion and conditional query subtree. Disclosure remains open through updates within the narrow arrangement. Returning from the built-in long-row arrangement starts collapsed, including strategy-selected transitions, while applied criteria and owner-held drafts survive. Collapse/switch unmounts borrowed views without discarding drafts or committing. Hiding a focused editor on resize restores its corresponding trigger's focus; retained visible editors preserve identity. Backends fulfill native controls/layout. Verify independent active states, exclusive panels, reset availability/guards, source order before actions, drafts, focus, context and narrow containment.
