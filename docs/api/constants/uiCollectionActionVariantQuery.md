# uiCollectionActionVariantQuery

Import from `@uninterface/uninterface` or `@uninterface/uninterface/backend`. This stable `UiStrategyQuery<UiCollectionActionVariant>` identity supplies the collection action surface concern. Custom strategies answer with `uiCollectionActionVariantQuery.answer(value)`; do not reconstruct its symbol.

See [uiCollectionActionVariant](../../strategies/uiCollectionActionVariant.md) for vocabulary, participating buttons, agreement with the generic variant concern, defaults and explicit-choice rules. Backend useUiButtonPresentation consumes the query at the existing button node. Blocking the query stops incoming answers from all families. Verify custom answers, scopes, family/query barriers and conflict recovery without remounting buttons.
