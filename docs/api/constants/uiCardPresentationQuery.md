# uiCardPresentationQuery

Import from `@uninterface/uninterface`. A `UiStrategyQuery<UiCardPresentation>` consumed by the logical `card` node. Custom strategy families can answer it; UiStrategy.block can stop all incoming answers to it.

Agreement requires whole-profile equivalence after filling omitted levels/properties from defaults. Object identity and property order do not matter. It does not merge complementary profiles, prefer a nearer attachment or compare native renderings. Differing -2 entries remain conflicting even if a backend's ordinary upper treatments match. Disagreement/no answer restores the complete default profile; uiHierarchyLevel negotiation remains independent.

Malformed custom answers are unsupported and ignored. Common factory declarations reject invalid structure immediately. Effective color roles are checked against installed theme support when consumed by UiCard; invalid theme colors do not silently become neutral.

See [uiCardPresentation](../../strategies/uiCardPresentation.md) for values/defaults and [UiCardPresentation](../types/UiCardPresentation.md) for the map. Verify structural agreement, query/family barriers, scope and fallback without relying on declaration order.
